# Трекер инициативы

Статический сайт трекера инициативы и бестиария. Интерфейс публикуется через GitHub Pages, а авторизация и синхронизация данных работают через Supabase.

## Публикация

Содержимое сайта находится в каталоге `dist`. Каждый push в ветку `main` запускает workflow `Deploy GitHub Pages` и автоматически публикует новую версию.

## Supabase

SQL-схема пользовательского архива находится в `supabase/user_archives.sql`.

После изменения домена добавьте новый адрес GitHub Pages в список разрешённых Redirect URLs проекта Supabase.
